# 📌 Problem: Design [Tên Hệ Thống]

## 1. 📖 Problem Statement
- Mô tả bài toán và yêu cầu của hệ thống
- Yêu cầu chức năng (functional requirements)
- Yêu cầu phi chức năng (non-functional requirements)

## 2. ❓ Clarifying Questions
- Danh sách các câu hỏi cần hỏi để làm rõ scope

## 3. 📐 High-Level Design
- Mô tả sơ đồ kiến trúc tổng quan của hệ thống
- Các thành phần chính: client, API Gateway, service layer, DB, cache, message queue...
- Sơ đồ (vẽ bằng Lucidchart/Excalidraw hoặc link kèm ảnh)

## 4. 💾 Database Design
- Chọn loại CSDL: SQL, NoSQL, time-series, graph...
- Bảng chính (table schema hoặc collection document)
- Mối quan hệ giữa các bảng (có thể kèm ERD)

## 5. 🧩 Component Design
- Authentication (nếu có)
- Caching (Redis, CDN…)
- Message Queue (Kafka, RabbitMQ…)
- Search, Analytics, CDN, API Rate Limiting...

## 6. ⚙️ Scalability and Reliability
- Horizontal vs Vertical scaling
- Load balancing
- Rate limiting
- Partitioning (Sharding)
- Replication
- Caching layers

## 7. 🧠 Trade-offs and Alternatives
- Vì sao chọn cách này?
- Ưu và nhược điểm
- Những lựa chọn khác có thể thay thế

## 8. 🧠 What I Learned
- Ghi chú bài học, tips rút ra
- Những phần còn yếu cần cải thiện
